# 8bit奶蛙桌宠

一只奶黄色、绿眼睛、软乎乎的像素桌宠。安静时呼吸、歪头、坐下和睡觉；你点它时，它会挥手、跳跃或笑到弯腰。

**v1.0.0 · Windows 桌宠 · 离线运行 · 免安装**

![奶蛙动作预览](docs/images/preview.gif)

本版采用已验收的 4 秒动画素材：每个主动作 24 帧/秒、96 个播放帧。图中的 v0.5 是动画素材的迭代编号，桌宠程序版本为 v1.0.0。

## 下载与启动

1. [下载 v1.0.0 完整包（程序 + 使用说明）](https://github.com/Hitxyz556/8bit-naifrog-desktop-pet/releases/download/v1.0.0/8bit-naifrog-desktop-pet-v1.0.0-win.zip)。也可以在[版本下载页](https://github.com/Hitxyz556/8bit-naifrog-desktop-pet/releases/tag/v1.0.0)只下载 `奶蛙桌宠.exe`。
2. 解压后双击 `奶蛙桌宠.exe`。
3. 奶蛙出现在桌面右下角。按住它可以移动；右键奶蛙或点击系统托盘图标可以打开菜单。

建议使用 Windows 10 / 11，系统需有 .NET Framework 4.8。程序无需 Python、Node.js、管理员权限或安装器。首次运行可能受到 Windows 对未签名程序的检查；本版本未购买代码签名证书。

## 怎么和它玩

| 操作 | 奶蛙的回应 |
| --- | --- |
| 在它附近停留约 0.3 秒 | 站着时好奇歪头；坐着和睡着时保持原姿势 |
| 单击头部 | 挥手 |
| 单击身体 | 轻压回应 |
| 双击角色 | 开心跳跃 |
| 1.2 秒内连续点肚皮 3 次 | 朝左抱住肚子大笑 |
| 按住并移动超过 6 个屏幕像素 | 抓住当前姿势拖动，身体轻轻拉伸 |
| 松开鼠标 | 消除拉伸，沿当前动作的收势恢复站立；快速拖动后会惊讶 |
| 点击睡着的奶蛙 | 睁眼、坐稳、站起，再挥手 |
| 在菜单开启小游戏 | 进入架势，点它触发成功跳跃；20 秒无互动后退出 |

肚皮双击会等待 1.2 秒识别窗口，以便让三连点优先；拖动不会再触发点击动作。普通互动只保留最新一次请求，避免动作排成长队。

没有互动时，奶蛙先站立；约 90 秒后坐下，约 5 分钟后睡觉。站立时偶尔歪头或短暂变成蛋形、鼠形。计时依据与奶蛙的互动，桌面其他地方的操作不计入。

## 12 种动作

![奶蛙12种动作总览](docs/images/actions.gif)

站立待机、蛋形摇摆、鼠形抖耳、弯腰大笑、挥手、睡觉呼吸、游戏架势、拖动、开心跳跃、好奇歪头、坐姿待机、惊讶回神。

不同姿势通过共同端点和过渡动画连接。实际拖动使用抓取时的当前画面做可逆变形，避免空中的跳跃突然变成站姿；菜单中的 A08 是固定拖动造型的演示。

## 菜单功能

- 暂停动画与待机、关闭自动待机、切换置顶。
- 调整大小为 75%、100%、150% 或 200%。
- 隐藏奶蛙、恢复到桌面右下角、逐个预览动作。
- 开始小游戏、查看简要说明、退出程序。

本版的位置和菜单设置仅在本次运行中生效。关闭后不留下设置文件，也不会自动随 Windows 启动。

## 开发与验证

源码使用 C# / Windows Forms，调用 Windows 的透明窗口接口。所有动画嵌入 exe，可直接移动程序，不依赖旁边的素材文件。

在已安装 .NET Framework 4.8 编译器的 Windows PowerShell 中，进入项目目录执行：

```powershell
./build.ps1 -Test
```

生成 `release/奶蛙桌宠.exe`。检查覆盖手势优先级、姿势路径、睡眠唤醒、最新输入替换、各动作中途拖动与恢复、暂停、小游戏和透明渲染。测试输出保存在忽略上传的 `test-artifacts/`。
