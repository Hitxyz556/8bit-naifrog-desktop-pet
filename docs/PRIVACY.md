# 隐私与发布范围

## 程序运行时

- 不包含网络请求、遥测、广告或自动更新功能。
- 不登录任何账号，不请求用户名、邮箱、密码或访问令牌。
- 不读取剪贴板、其他窗口内容、键盘输入、摄像头、麦克风或屏幕截图。
- 不扫描用户文件，不记录鼠标轨迹，不生成正常运行日志。
- 不保存位置、设置或互动记录；仅在运行中的内存里保留。
- 不安装服务，不添加开机启动项，不要求管理员权限。

桌宠只处理它自己窗口收到的点击与拖动，并读取当前鼠标坐标，判断是否在角色附近。坐标只用于即时动作和位置，不写入文件、不上传。

程序使用一个固定名称的单实例互斥锁，以及 Windows 通知区域图标。动画直接嵌入程序，在内存中解码，不解压到个人目录。

开发者显式使用 `--self-test` 或 `--smoke-test` 时，会在指定位置写入测试结果；普通双击启动不执行这些测试，也不写这些文件。

## 公开仓库包含什么

公开内容仅为 C# 源码、构建脚本、经过整理的角色动画资源、动作预览、介绍、使用说明与验证摘要。可执行程序和便携压缩包用于发布下载。

不上传整个原始工作目录；不上传聊天记录、截图附件路径、原始文档元数据、浏览器数据、账号配置、环境变量、个人文件、凭据、编译调试符号或测试时的真实桌面截图。

PNG 素材重新保存，移除附加元数据，并清空完全透明像素的隐藏颜色。嵌入素材包仅使用相对资源名称。编译关闭调试符号；提交作者使用项目名称和通用无回复地址，避免泄露本机 Git 邮箱。

## 保证的边界

发布前会检查实际源码、图片元数据、资源压缩包、二进制和下载包是否包含本机用户路径或明显凭据。该检查说明本次发布文件的审查结果，不是对所有软件漏洞或平台行为的无限保证。

公开 GitHub 仓库会显示拥有该仓库的 GitHub 账号，以及 GitHub 平台正常展示的仓库活动。桌宠本身不读取或收集该账号信息。

反馈问题时，请只提供版本、操作步骤和奶蛙相关的画面，避免在 Issue 中粘贴密码、令牌、个人目录、未遮挡的工作内容或聊天记录。
