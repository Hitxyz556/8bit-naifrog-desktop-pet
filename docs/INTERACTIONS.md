# v1.0 互动规则与动作调度

## 手势优先级

拖动 > 肚皮三连点 > 双击 > 单击。按下立即给轻压反馈，等待手势识别期间保持自然动画。

| 手势 | 条件 | 动作 |
| --- | --- | --- |
| 悬停 | 在可见角色周围约 0.3 个身高内停留 0.3 秒 | 站立时 A10 |
| 头部单击 | 等待 300 毫秒双击窗口 | A05 |
| 身体单击 | 轻压已在按下时反馈 | 不重复播放长动作 |
| 双击 | 300 毫秒内，位置距离不超过约 0.1 个身高 | A09 |
| 肚皮三连点 | 1.2 秒内 | A04 |
| 拖动 | 按下后移动超过 6 个屏幕像素 | 当前姿势接管；取消点击 |

肚皮单击、双击等首击后的 1.2 秒窗口结束再提交，避免先跳跃后误判挠痒。相隔超过 300 毫秒的两次肚皮点击不会当成双击。

## 稳定姿势

S 站立、C 坐姿、Z 睡眠、E 蛋形、M 鼠形、G 游戏架势、D 固定拖动演示。路径通过 T01–T12 连接；主动作首末帧复用相同标准姿势。

坐姿响应站立互动前先起身；睡眠点击经 Z → C → S → 挥手；变形响应前先返回 S。小游戏成功经 G → S → 跳跃 → G，停止时回 S。

## 动态抓取

抓取时保留实际当前帧，用抓取点作为变形中心，限制拉伸幅度并保留透明边界。松手先回到未拉伸的捕获姿势，再加速完成剩余的收势帧及返回 S 的路径；不重放动作的起手。快速拖动阈值约为每秒 3 个站立身高，恢复后追加 A12。

动态抓取使用可逆图像变形，不把角色替换成统一趴姿。固定 A08/T11/T12 仍用于动作菜单预览和姿势路径。

## 调度与冷却

身体同时只播放一个动作。最新普通请求替换旧请求；队列最多一项，过期 3 秒丢弃。拖动清除队列，唤醒中的点击合并，普通动作从当前姿势收束后接入。

跳跃、大笑冷却 3 秒，挥手冷却 2 秒，歪头冷却 5 秒。冷却不阻止按下时的轻压反馈。

## 自动待机

站立 → 90 秒无互动后坐下 → 5 分钟无互动后睡眠。20–40 秒低频好奇动作；距用户互动至少 30 秒后可出现变形彩蛋，变形间隔至少 180 秒。自动动作不重置用户无互动时间。

游戏仅由用户启动，20 秒无游戏输入后退出。隐藏时不补播累积动作；恢复显示时回稳定站立。位置和偏好只在内存中保留。
